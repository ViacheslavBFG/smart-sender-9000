# Smart Sender 9000 

Невеликий застосунок: вхід, список вебхуків і редагування. API імітує [MSW](https://mswjs.io/).

## Запуск

```bash
npm install
npm run dev
```

Збірка: `npm run build`. Тест: `npm test`.

Сайт: https://viacheslavbfg.github.io/smart-sender-9000/

Тестовий акаунт: `admin@gmail.com` / `helloworld`. На екрані входу ці дані можна натиснути й скопіювати. Після входу в шапці буде Олена Головач.

Після перезавантаження сторінки потрібно увійти знову. Параметри списку (`page`, `search`) лишаються в URL.

## Ключові рішення

Сесію тримає мок у пам’яті => це аналог HttpOnly-cookie. Клієнт бачить лише `device_session_token` у змінній модуля (не в `localStorage` і не в URL) і прапорець, що вхід відбувся. `fingerprint` => 32 hex-символи, створюється один раз і лежить у `localStorage`.

Усі запити йдуть через один клієнт. Він заздалегідь бере `GET /csrf`, ставить `X-Requested-With` і передає `X-CSRF-TOKEN` на `POST`/`PUT`. На `419` токен запитується знову і запит повторюється один раз.

На `401` клієнт викликає `POST /auth/token/rotate` і повторює вихідний запит один раз. Паралельні `401` чекають на один спільний rotate: поки він іде, нові виклики отримують той самий promise. Сам rotate цей механізм не запускає. Помилка rotate або повторний `401` скидають локальну сесію, чистять кеш React Query і повертають на вхід.

Список і пошук живуть у query-параметрах. Дані сервера => у TanStack Query, повтор авторизації => під ним, у транспорті, щоб кеш не лікував протухлу сесію сам.

Сесія в моку живе 30 секунд. Rotate продовжує її ще на 30. До `issue` і після `revoke` rotate відповідає `400`.
